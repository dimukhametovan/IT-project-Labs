# 🛠 Технологии и библиотеки

Проект разработан с использованием следующих инструментов:

### 📦 Основные зависимости

| Библиотека          | Назначение                                                             |
| ------------------- | ---------------------------------------------------------------------- |
| `fastapi`           | Веб-фреймворк для быстрого создания API с автоматической документацией |
| `uvicorn[standard]` | ASGI-сервер для запуска FastAPI приложений                             |
| `sqlalchemy`        | ORM для работы с реляционными базами данных                            |
| `pydantic`          | Валидация данных и создание моделей для API                            |
| `python-dotenv`     | Работа с переменными окружения из .env файлов                          |
| `passlib[bcrypt]`   | Хеширование паролей с использованием алгоритма bcrypt                  |
| `python-jose`       | Реализация JWT для аутентификации и авторизации                        |
| `python-multipart`  | Обработка multipart-форм (необходимо для загрузки файлов)              |
| `email-validator`   | Валидация email-адресов                                                |
| `axios`             | HTTP-клиент для работы с API (используется в фронтенд части)           |

### 🗃 База данных

- SQLite (легковесная встроенная СУБД)
- Таблицы: users, students, grades для пользователей, студентов и оценок соответственно

### ⚙️ Вспомогательные инструменты

- Uvicorn (ASGI-сервер для запуска FastAPI)

# Структура проекта

### Backend

```pgsql
it-project/
├── app/
│   ├── main.py              ← Точка входа: здесь запускается FastAPI и подключаются маршруты
│   ├── database.py          ← Подключение к SQLite и создание базовой схемы
│   ├── models/              ← SQLAlchemy модели — описывают таблицы БД
│   │   ├── grade_m.py       ← Модель оценок (Garde)
│   │   ├── student_m.py     ← Модель студента (Student)
│   │   └── user_m.py        ← Модель пользователя (User)
│   ├── schemas/             ← Pydantic схемы — описывают входные/выходные данные API
│   │   ├── grade.py
│   │   ├── student.py
│   │   └── user.py
│   ├── auth/                ← Всё, что связано с авторизацией (JWT, хеширование пароля и т.п.)
│   │   ├── security.py      ← Хеширование паролей, создание токенов
│   │   └── dependencies.py  ← Получение текущего пользователя из токена
│   ├── routers/             ← Маршруты API (регистрация, вход и профиль)
│   │   └── auth.py
│   │   └── student.py
```

# Настрока среды окружения

```bash
# 1. Активируй виртуальное окружение

source venv/bin/activate      # на Linux/Mac
venv\Scripts\activate         # на Windows

# 2. Установи зависимости
pip install -r requirements.txt

# 3. Запусти сервер
uvicorn app.main:app --reload
```

Сервер: http://127.0.0.1:8000/docs
